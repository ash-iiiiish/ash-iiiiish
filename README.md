## `$ ls ./featured-projects`

### 01 / Enterprise AI Knowledge Copilot
**Agentic RAG · LangGraph · MCP · PostgreSQL**

An enterprise knowledge assistant designed to combine document retrieval with tool-using AI workflows.

- Integrated **6+ MCP tools** for document search, policy retrieval, ticket management, employee lookup, and database operations.
- Built retrieval workflows using PostgreSQL, pgvector, reranking, and retrieval validation.
- Used LangGraph for routing and orchestration, with LangSmith for tracing.
- Explored Self-RAG/CRAG patterns and local/cloud model integration through Ollama and Groq.

**Focus:** Enterprise knowledge access, tool orchestration, and retrieval reliability.
